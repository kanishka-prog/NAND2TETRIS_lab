# Nand2Tetris Lab Work

This repository contains my lab work for the Nand2Tetris course, based on *The Elements of Computing Systems*.

## Lab Structure

- **Lab-01:** Logic Gates
- **Lab-02:** Combinational Chips
- **Lab-03:** Sequential Logic
- **Lab-04:** Machine Language and related exercises

## Tools Used

- Hardware Description Language (HDL)
- Nand2Tetris Hardware Simulator
- Visual Studio Code
- Git and GitHub

## Purpose

To understand computer architecture and digital systems by implementing and testing hardware components step by step.
